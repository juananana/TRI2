# TRI AAAI-27 项目结构

> 本文件保留作中文详细说明；快速入口请先阅读同目录的 `README.md`。

本目录是论文源码目录。完整实验代码和数据位于仓库根目录的 `experiments/tri_artifact/`，匿名提交包位于 `submission/`。官方 AAAI 文件名保持不变，便于直接上传 Overleaf。

## 顶层正式文件

- `AnonymousSubmission2027.tex` / `.pdf`：匿名主论文源码与已验证 PDF。
- `supplementary_material.tex` / `.pdf`：补充材料源码与已验证 PDF。
- `aaai2027.sty`、`aaai2027.bst`：AAAI-27 官方模板文件。
- `aaai2027.bib`：参考文献数据库。
- `ReproducibilityChecklist.tex`：官方可复现性清单。
- `Figures/`：主论文使用的最终 PDF 图。

## 实验与复现

- `experiments/tri_artifact/data/`：冻结 benchmark 数据。
- `experiments/tri_artifact/runs/`：原始模型运行结果。
- `experiments/tri_artifact/reports/`：统计报告、协议与结果来源映射。不要复制到本目录。
- `experiments/tri_artifact/tri/`：控制器和评测实现。
- `experiments/tri_artifact/scripts/`：实验、分析和匿名包构建脚本。
- `experiments/tri_artifact/tests/`：科学计算与 artifact 测试。
- `experiments/tri_artifact/human_validation/`：人工验证材料。私有工作簿、答案映射和协调表仅保存在本机，并由根目录 `.gitignore` 排除。

## 常用命令

编译论文：

```bash
cd paper
latexmk -pdf -interaction=nonstopmode -halt-on-error AnonymousSubmission2027.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error supplementary_material.tex
```

运行完整测试：

```bash
cd experiments/tri_artifact
PYTHONPATH=. python3 -m unittest discover -s tests
```

重建匿名包：

```bash
cd experiments/tri_artifact
python3 scripts/build_current_supplement.py \
  --output ../../submission/tri_anonymous_artifact_current.zip
```

## 隐私与版本规则

1. 不把 API key 写入文件、命令脚本或 Git。
2. 不提交 `experiments/tri_artifact/human_validation/` 中的身份信息、私有映射和原始 XLSX。
3. 论文数字必须能追溯到冻结数据、原始 run 和报告脚本。
4. 顶层官方文件名不改名；旧版本统一从本工作目录移除并保存在外部清理前快照中。
