# Figure Backup

This directory stores historical paper figures and candidate renders that are not imported by the
current LaTeX sources. `candidates-round8-v3/` is the accepted preview/export set for the current
Figure 2--5 designs; the corresponding final PDFs live in `../Figures/`.

Exact duplicate files named with `_副本` are intentionally removed. Failed round-8 candidates are
also removed after review. Keep one representative copy of materially different historical
designs for provenance, but do not copy unused assets back into `../Figures/`.
