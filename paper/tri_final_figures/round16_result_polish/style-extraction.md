# Style Extraction From User References

The references are educational posters that contrast default spreadsheet charts with cleaner
scientific charts. Their poster backgrounds and decorative stickers are not copied. Extraction
focuses on the embedded scientific charts and the stated design rules.

- Box stroke: about 0.7 px; data strokes about 1.2 px.

- Same-row horizontal gap: about 18 px.

### 5. Arrow Grammar

- Default type: straight comparison lines; no decorative arrows.
- Color: series color.
- Arrowhead: none.
- Routing: straight.
- Labels: short direct labels/legend at about 7-8 pt.
- Color coding: yes, by series.

### 6. Icon Language

- Icons: none inside scientific plots.
- Typical size/stroke/source: not applicable.
- Decorative poster icons are excluded from the paper chart contract.

### 7. Density & Composition

- Type: small-multiple bar and line plots.
- Major regions: one plot plus one concise legend.
- Density: medium.
- Whitespace: moderate.
- Panel labels: none inside examples.
- Legend: compact, above or right.
- Caption: outside the plot.

## Synthesized Style Contract

### Common Across References

| parameter | chosen value | evidence |
|---|---|---|
| Background | white | all scientific chart examples |
| Typography | one sans-serif family, 7-10 pt hierarchy | references 1-3 |
| Axes | thin dark-neutral strokes with explicit units | references 1-2 |
| Palette | 5-8 muted, role-based colors | references 1-3 |
| Grid | absent or very light | references 1-2 |
| Legends | compact; direct labels when clearer | references 1-2 |
| Error bars | visible but thin, series colored | references 1-2 |
| Decoration | none inside data plots | all chart examples |
| Layout | aligned, medium density, moderate whitespace | references 1-3 |

### Adaptation Decisions

| parameter | poster references | chosen for TRI | reason |
|---|---|---|---|
| Palette | gray/red or muted multicolor | user-specified lavender/coral/teal | explicit user preference and cross-figure identity |
| Panel labels | often absent | A/B retained | necessary for caption references |
| Icons | absent in result plots | none | no quantitative semantic role |
| Rounded cards | poster-level decoration | none | wastes single-column space |
| Font | mixed poster fonts | DejaVu Sans | embedded, reproducible, already used by paper figures |
