# TRI final paper figures

This package contains reproducible Python/matplotlib sources for the TRI paper figures. Historical
scripts remain for provenance; `plot_round8_figures.py` generates the current main-paper result
set from frozen summary CSV files.

## Historical outputs

- `fig_resolution_policy_phase_space.*`
- `fig_shared_eligible_target_flow.*`
- `fig_wrong_write_decomposition.*`
- `fig_decision_visibility_effect_sizes.*`
- `fig_source_model_transfer_fingerprints.*`
- `fig_enforcement_repairs_harms.*`

Each figure is exported as PDF, SVG, and 300-dpi PNG. The PDFs/SVGs are vector graphics suitable for LaTeX.

## Generate all figures

```bash
python -m pip install -r requirements.txt
python plot_all.py
```

To use an external copy of the data package:

```bash
python plot_all.py --data-dir /path/to/summary_csv --output-dir /path/to/outputs
```

## Distinctive figure candidates

The alternative author-driven set adds a referent trajectory/tree, parallel-coordinate policy
fingerprints, a conditional evidence tree, and source-specific radar fingerprints paired with

```bash
python plot_distinctive.py
```

These candidates are written to `outputs/distinctive/` as PDF, SVG, and 300-dpi PNG files. The
radar panel is intended as a heterogeneity overview; the adjacent forest panels remain the precise
inferential display.

## AAAI single-column set

The compact main-paper set uses one visual field per figure and a fixed 3.35-inch width:

- `fig1_referent_trajectory_v2`: concrete email requests and observed Preserve failure.
- `fig2_policy_phase_space_v2`: Generic-to-CTA policy trajectories with changed-winner PairAcc.
- `fig3_shared_eligible_substitution_v2`: shared-eligible substitution dumbbells with Wilson intervals.
- `fig4_wrong_write_attribution_v2`: complete TRI versus non-core wrong-write attribution.
- `fig5_decision_visibility_forest_v2`: claim-focused authored and transfer effects in one forest plot.

Generate the set with:

```bash
MPLBACKEND=Agg python plot_single_column.py
```

PDF, editable SVG, and 300-dpi PNG files are written to `outputs/single_column/` with the default
`_v2` suffix. Use `--output-dir` to write directly to the paper figure directory. Existing figure
files with other versions are not overwritten.

## Design decisions

- No figure title or caption is embedded in the graphic; add captions in LaTeX.
- A single restrained palette is used throughout: muted blue-teal for the focal condition, muted coral for substitutions/harms, amber only for post-hoc results, and neutral gray for controls.
- PDF/SVG text remains editable (`pdf.fonttype=42`, `svg.fonttype='none'`).
- The phase-space plot uses a true broken y-axis to compress the empty 22-50% interval.

## Data note

The phase-space script corrects several inaccuracies that can arise in image-generation mockups. It reads the exact v3 CSV values, including Rule* PairAcc 68/80, Qwen Lifecycle-Gated PairAcc 77/80, and deterministic control locations at (20,100) and (100,20).
