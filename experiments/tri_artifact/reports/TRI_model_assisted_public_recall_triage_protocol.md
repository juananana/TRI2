# Model-Assisted Public Recall Triage Protocol

**Status:** post-primary zero-API model-assisted triage; not independent review.

## Claim Tested

This audit tests whether the existing public-suite coverage conclusion is obviously vulnerable to
missed near-cases in the already frozen audit artifacts. It does not test deployed prevalence,
native benchmark performance, or TRI behavior of any model agent.

## Boundary

The output is a triage queue with candidate feature labels. It may be used to prioritize human
review and to describe a model-assisted sensitivity check. It must not be described as independent
human recall calibration, benchmark adjudication, or a new public benchmark result.

## Frozen Inputs

- `reports/benchmark_coverage_checklist.json`
- `reports/official_toolsandbox_tri_prevalence_audit.json`
- `reports/appworld_public_trace_tri_audit.json`
- `reports/official_tau3_native_tri_audit.json`
- `data/external_public_opportunity_candidates_v1.jsonl`
- Injected known-label controls generated by `tri.public_audit_sensitivity.build_controls`

## Rubric

Each record receives candidate labels for:

1. stable entity ID;
2. observable pre-refresh binding;
3. independent post-binding transition;
4. competing same-role entity;
5. changed selector winner;
6. old entity remains actionable;
7. later target mutation;
8. evaluable authorized target.

Labels are `yes`, `no`, or `partial`. `partial` is non-strict. A strict candidate requires all
eight labels to be `yes` and still requires human adjudication before any manuscript claim changes.

## Stopping Rule

The zero-API triage run completes when it writes:

- `data/model_assisted_public_recall_triage_v1.jsonl`
- `reports/model_assisted_public_recall_triage_v1.json`
- `reports/model_assisted_public_recall_triage_v1.md`

The report must include all six suites, closest cases, stratified/high-risk natural records, and
60 injected controls. The injected controls check implementation sensitivity only; they do not
measure natural benchmark recall.

## Interpretation

If no natural strict candidates are proposed, the result modestly strengthens confidence that the
existing deterministic audit did not miss an obvious strict native opportunity in the reviewed
records. It does not prove recall over all source units. If any strict candidate is proposed, the
paper conclusion remains unchanged until two independent human reviewers inspect the upstream
source and adjudicate the record.
