# TRI 人工语义验证：用户友好操作手册

## 你现在先做什么

独立英文改写已经完成，不需要再次联系改写者。现在只需找 3 位没有参与 TRI 设计的
英文标注者，并分别发送下列一个文件：

- `最终分行版_标注者1.xlsx`
- `最终分行版_标注者2.xlsx`
- `最终分行版_标注者3.xlsx`

不要发送旧的 JSON 版、CSV 版、总填写包或 `annotation_key_private.csv`。三个最终文件
包含相同的 100 道题，但题目顺序各不相同。

你的试填结果不能进入论文统计，因为你已经知道论文假设和标签设计。它只用于发现表格或说明是否难用。

## 为什么任务文本仍是英文

操作说明和列名均为中文，但原始任务、状态字段和自然改写保留英文。论文评估的是英文 Agent 指令；如果把题目翻译成中文，会同时引入翻译差异，无法验证原 benchmark 的构念效度。

## 需要哪些人

| 角色 | 人数 | 任务 | 预计用时 | 能否由论文作者担任 |
|---|---:|---|---:|---|
| 协调者 | 1 | 招募、分发、收表、保管盲化答案 | 20--30 分钟 | 可以 |
| 独立改写者 | 1 | 将 50 条英文指令自然改写成英文 | 45--75 分钟 | 不可以 |
| 独立标注者 | 3 | 各自独立判断 100 个目标 | 每人 60--90 分钟 | 不可以 |

改写者不能同时担任标注者。三名标注者不能讨论答案，也不能看到答案键、TRI 标签、论文结果或其他人的表格。

## 第一阶段：独立英文改写

发给改写者：`01_独立改写者填写表_中文列名.csv`。

只填写两列：

- `英文自然改写（必填）`：保持操作含义，但像真实用户一样换一种自然说法。
- `改写者备注（可选）`：若原句确实存在歧义，在这里说明，不要自行消除歧义。

禁止事项：

- 不加入目标 ID；
- 不加入 `preserve`、`reevaluate`、`binding`、`TRI` 等研究术语；
- 不查看初始状态、刷新状态或正确答案；
- 不做机械同义词替换，尽量改变自然句式。

收回后不要手工复制到其他文件。运行中文转换工具导入，再生成三份随机化盲标表：

```bash
python3 scripts/chinese_human_validation_forms.py --import-rewrites
python3 scripts/make_human_validation_packet.py --compile
python3 scripts/chinese_human_validation_forms.py --export-annotators
```

## 第二阶段：三人独立标注（当前阶段）

分别发送：

- `最终分行版_标注者1.xlsx`
- `最终分行版_标注者2.xlsx`
- `最终分行版_标注者3.xlsx`

每份表只显示不透明题号，不显示原始/改写版本、实验分组或来源编号。每题阅读英文指令、
初始状态、刷新后状态和动作约束，在 `你的答案` 中只填：

- 候选 ID 中的一个，例如 `EM-104`；
- `REJECT`：不应对任何实体执行动作；
- `CLARIFY`：根据给定信息无法得到足够明确的唯一答案。

`信心1到5` 可选：1 表示很不确定，5 表示很确定。不要因为觉得系统“最好做点什么”而回避 `REJECT` 或 `CLARIFY`。

### 为什么看起来少了列

没有丢失实验信息。来源任务编号、原文/改写类型、anchor/dynamic、更新类型和标准答案
完整保存在协调者专用的 `annotation_key_private.csv` 中。正式标注表故意隐藏这些列，
否则标注者会从实验标签或标准答案受到暗示，破坏盲标。标注所需的信息仍完整保留：
任务指令、初始状态、刷新后状态、动作前置条件、候选答案、作答、信心和备注。状态中的
每个对象按 ID 独立换行，每个候选答案也独立换行。

## 第三阶段：回收与统计

三份中文表回收后执行：

```bash
python3 scripts/chinese_human_validation_forms.py --import-annotators
python3 scripts/analyze_human_validation.py \
  --forms human_validation/annotator_1.csv \
          human_validation/annotator_2.csv \
          human_validation/annotator_3.csv \
  --key human_validation/annotation_key_private.csv
```

论文至少报告：参与人数、筛选条件、majority-gold accuracy、raw agreement、Fleiss' kappa、Krippendorff's alpha、CLARIFY majority rate，以及 explicit/implicit、original/rewrite 分组。

## 可直接发送的知情同意文本

> 本任务用于一项关于英文工具型 AI Agent 指令理解的学术研究。你将阅读虚构任务和结构化状态，不涉及真实个人信息。你的匿名答案可能以汇总统计形式用于论文和补充材料。参与自愿，可随时停止；停止不会产生不利后果。提交表格表示你已理解并同意匿名研究使用。请不要填写姓名、电话、邮箱等身份信息。

## 数据管理

- 参与者只使用匿名编号，如 `RW01`、`A01`、`A02`、`A03`。
- 不收集姓名、联系方式或不必要人口信息。
- `annotation_key_private.csv` 只由协调者保管，不发送给参与者。
- 若标注一致性低，必须如实报告歧义率，不能删除不利项目后只报告更高结果。
